# Fotos de exemplo

Estas imagens são **sintéticas** (texturas geradas por computador), não fotos de plantas.
Servem só para o simulador exercitar o envio de fotos e a avaliação de qualidade.
A `foto_sintetica_5_desfocada.jpg` é desfocada e escura de propósito.

No app Android, as fotos são tiradas pela câmera do celular.
